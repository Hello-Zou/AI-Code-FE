响应式导航栏组件

这是一个简洁实用的响应式导航栏，包含移动端汉堡菜单和桌面端水平导航。适用于大多数现代网站。

创建日期：2026年1月30日

// 响应式导航栏 JavaScript 代码 const hamburger = document.querySelector('.hamburger'); const navMenu = document.querySelector('.nav-menu'); hamburger.addEventListener('click', () => { hamburger.classList.toggle('active'); navMenu.classList.toggle('active'); });

关于此组件

这个导航栏组件使用纯HTML、CSS和JavaScript实现，无需任何外部依赖。它具有以下特性：

  • 响应式设计 - 自动适应不同屏幕尺寸
  • 汉堡菜单动画 - 点击时显示平滑过渡效果
  • 当前页面高亮 - 显示用户当前位置
  • 平滑滚动 - 点击导航项时平滑滚动到对应部分

功能特性

1. 移动端优化：在屏幕宽度小于768px时自动切换为汉堡菜单。

2. 可访问性：使用语义化HTML标签，支持键盘导航。

3. 性能优化：使用CSS过渡实现动画，性能高效。

4. 易于定制：通过CSS变量可以轻松更改颜色、尺寸等样式。

实现原理

这个导航栏的核心原理是通过CSS媒体查询检测屏幕宽度，在移动端隐藏导航菜单并显示汉堡按钮。点击汉堡按钮时，通过JavaScript切换CSS类来显示/隐藏菜单。

/* 核心CSS - 移动端菜单切换 */ .nav-menu { display: flex; /* 桌面端显示 */ } @media screen and (max-width: 768px) { .nav-menu { position: fixed; left: -100%; /* 隐藏菜单 */ top: 70px; flex-direction: column; } .nav-menu.active { left: 0; /* 显示菜单 */ } }
